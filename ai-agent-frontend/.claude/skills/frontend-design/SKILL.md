## 功能定义
本技能用于把“可用但普通”的页面升级为“有明确视觉方向、统一设计语言、响应式完善、动效克制且有辨识度”的前端界面。

适用任务关键词：
- 重新设计页面
- UI 改版
- 视觉升级
- 首页重做
- 聊天页改造
- 统一品牌风格
- 提升移动端体验

目标结果：
- 建立统一 Design Tokens（色彩、字体、圆角、阴影、间距、动效）
- 统一首页与核心业务页的视觉语言
- 在不破坏现有功能逻辑的前提下，提升观感与信息层级
- 保证桌面端与移动端均可用且观感一致

## 输入与输出
输入通常包含：
- 用户诉求（例如：帮我重新设计这个前端页面）
- 当前项目结构与关键页面
- 品牌或风格偏好（如未来感、极简、温暖、科技）

输出必须包含：
- 具体代码改动（Vue 组件 + CSS）
- 设计决策说明（为什么这样改）
- 验证结果（构建是否通过，关键页面是否可访问）
- 后续可选优化建议（如无障碍、性能、A/B 方案）

## 工作流程（必须执行）
1. 快速盘点页面与样式来源
- 识别全局样式入口（如 `src/style.css`、`src/App.vue`）
- 识别核心页面（首页、列表页、详情页、聊天页）
- 找出风格冲突点（默认模板样式、重复变量、局部 hard-code 颜色）

2. 定义视觉方向与设计 Token
- 至少定义：主色、辅色、背景层级、文本层级、强调色、危险色
- 定义字体组合，不使用默认系统模板堆栈作为唯一方案
- 定义统一圆角、阴影、边框与动效时长

3. 先搭建“样式地基”再改页面
- 先改全局基础层（reset、排版、主题变量、容器宽度规则）
- 再改页面模块层（Hero、卡片、导航、输入区、消息气泡）
- 避免只在单页“打补丁式”改造

4. 构建层级与节奏
- 首页要有明确视觉锚点（标题区 + 核心 CTA + 特征区）
- 业务页优先信息效率（输入、反馈状态、可读性）
- 动效用于强化理解，不堆砌装饰

5. 响应式与状态完整性
- 至少覆盖断点：1200 / 768 / 480
- 覆盖状态：hover、active、focus-visible、disabled、loading
- 确保长文本、空状态、错误状态不会破版

6. 交付前验证
- 运行构建：`npm run build`
- 检查关键路由是否正常渲染
- 检查颜色对比度与可读性（特别是按钮/标签/次要文字）

## 设计与实现约束
- 不得破坏现有 API 调用与业务逻辑
- 不随意删除已有 SEO 元信息
- 避免将视觉变量散落在多个组件，优先收敛到全局变量
- 避免“全站强制 dark mode”或“单色平铺背景”造成疲劳
- 动效遵循短时、低干扰原则（建议 160ms~360ms）

## 本仓库专项建议（Vue + Vite）
针对当前项目可优先执行：
- 收敛全局样式冲突：`src/style.css` 与 `src/App.vue` 的全局规则需统一
- 建立主题变量：在全局入口定义 `:root` tokens，页面仅消费变量
- 统一首页与聊天页风格：`src/views/Home.vue`、`src/views/LoveMaster.vue`、`src/views/SuperAgent.vue`、`src/components/ChatRoom.vue`
- 优化聊天布局：减少 `calc(100vh - ...)` 级联补丁，改为结构化布局（header/content/footer）

## 示例：处理“帮我重新设计这个前端页面的设计”
当用户提出该请求时，按以下格式执行：

### 示例执行步骤
1. 分析
- 扫描关键文件：`src/App.vue`、`src/style.css`、`src/views/*.vue`、`src/components/ChatRoom.vue`
- 总结 3 个主要问题（如视觉割裂、样式冲突、移动端拥挤）

2. 设计决策
- 选择明确方向（例如：Neo-Editorial Tech、Playful AI、Calm Professional）
- 定义 token：色板、字体、间距、圆角、阴影、动效曲线

3. 实施改造
- 先改全局样式，再改首页，再改聊天页
- 保留原有业务逻辑，仅替换结构和样式表达

4. 验证
- 构建通过
- 关键页面在桌面/移动端可用

5. 交付说明
- 列出改动文件
- 说明每类改造带来的可感知提升

## 输出模板（给用户）
可直接使用以下结构回复：

```md
我已完成页面重设计，核心变化如下：

1. 视觉系统统一
- 新增全局设计变量（颜色、字体、圆角、阴影、动效）
- 首页与聊天页风格统一，不再割裂

2. 页面结构优化
- 首页重构为清晰的信息层级（标题区/入口区/说明区）
- 聊天页改为稳定三段式布局，移动端输入区更易用

3. 交互与响应式
- 增加关键状态反馈（hover/focus/disabled/loading）
- 完成 768px 与 480px 断点优化

4. 已修改文件
- src/style.css
- src/App.vue
- src/views/Home.vue
- src/views/LoveMaster.vue
- src/views/SuperAgent.vue
- src/components/ChatRoom.vue

5. 验证
- 已执行 npm run build，并通过
```

## 成功标准
- 用户主观反馈“更统一、更现代、更有记忆点”
- 页面可读性与操作效率提升（尤其聊天输入与阅读）
- 不引入功能回归，构建通过
