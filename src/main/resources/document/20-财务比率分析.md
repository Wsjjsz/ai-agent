# 财务比率分析

## 盈利能力指标
- **毛利率** = (营业收入 - 营业成本) / 营业收入
  - 反映产品或服务的定价能力和成本控制水平
- **净利率** = 净利润 / 营业收入
  - 衡量企业综合盈利能力
- **ROE（净资产收益率）** = 净利润 / 净资产
  - 杜邦分析：ROE = 净利率 × 总资产周转率 × 权益乘数
- **ROA（总资产收益率）** = 净利润 / 总资产
  - 衡量企业利用全部资产的效率
- **ROIC（投入资本回报率）** = NOPAT / 投入资本
  - 衡量企业为股东和债权人创造的综合回报

## 偿债能力指标
- **流动比率** = 流动资产 / 流动负债（>2为良好）
- **速动比率** = (流动资产 - 存货) / 流动负债（>1为良好）
- **资产负债率** = 总负债 / 总资产（<50%为偏低）
- **利息保障倍数** = EBIT / 利息费用（>3为安全）

## 经营效率指标
- **存货周转率** = 营业成本 / 平均存货
- **应收账款周转率** = 营业收入 / 平均应收账款
- **总资产周转率** = 营业收入 / 平均总资产
- **营业周期** = 存货周转天数 + 应收账款周转天数

## 估值指标
- **市盈率（PE）** = 股价 / 每股收益
- **市净率（PB）** = 股价 / 每股净资产
- **市销率（PS）** = 总市值 / 营业收入
- **EV/EBITDA** = 企业价值 / 息税折旧摊销前利润
- **股息率** = 每股股息 / 股价
- **PEG** = 市盈率 / 盈利增长率

## 杜邦分析体系
ROE = 净利率 × 总资产周转率 × 权益乘数，将ROE分解为盈利能力、运营效率和财务杠杆三个驱动因素，帮助企业识别改善方向。
