# 税务规划基础

## 中国主要税种
- **个人所得税**：对个人收入征收，税率3%-45%
- **增值税**：对商品和服务增值额征收
- **企业所得税**：对企业利润征收，税率25%
- **印花税**：对合同、证券交易等凭证征收
- **契税**：对不动产交易征收，税率3%-5%

## 个人所得税优化策略
### 合理利用专项附加扣除
- 子女教育：每个子女每月2000元
- 继续教育：学历教育每月400元
- 大病医疗：超过15000元部分据实扣除
- 住房贷款利息：每月1000元
- 住房租金：每月800-1500元
- 赡养老人：每月2000-3000元
- 3岁以下婴幼儿照护：每月2000元

### 年终奖计税优化
- 全年一次性奖金可选择单独计税或并入综合所得
- 单独计税：奖金÷12确定适用税率
- 建议对比两种方式选择税负较低的方案

## 投资中的税务考虑
- 股票转让所得暂免征收个人所得税（限A股流通股）
- 股息红利按持有时间差异化征税：
  - 持有1年以上：免征
  - 持有1个月至1年：减按50%计入应纳税所得额
  - 持有1个月以内：全额计入
- 基金分红免税，但赎回产生的价差需纳税
- 国债利息收入免征个人所得税
