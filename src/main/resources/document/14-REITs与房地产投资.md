# REITs与房地产投资

## 什么是REITs
REITs（房地产投资信托基金）是汇集投资者资金、投资于房地产相关资产并分配大部分收益的信托基金。投资者通过购买REITs份额间接参与房地产投资。

## REITs的特点
- **流动性高**：在交易所上市交易，买卖方便
- **门槛低**：几百元即可参与
- **分红稳定**：法律规定90%以上应税收入必须分配给持有人
- **分散风险**：投资于多个物业类型和区域
- **专业管理**：由专业团队运营管理

## REITs的分类
- **权益型REITs**：直接拥有并经营房地产，收入主要来自租金
- **抵押型REITs**：投资于房地产抵押贷款或抵押贷款证券
- **混合型REITs**：同时进行权益型和抵押型投资

## 中国REITs市场
- 2021年首批公募REITs上市
- 目前以基础设施REITs为主（产业园、仓储物流、高速公路等）
- 保障性租赁住房REITs逐步推出
- 商业地产REITs正在试点推进

## 房地产投资的收益来源
- 租金收入（现金流）
- 房价增值（资本利得）
- 税收优惠（如折旧抵扣）
- 杠杆效应（通过按揭放大收益）

## 影响房地产市场的因素
- 利率和信贷政策
- 人口结构和城镇化进程
- 土地供给政策
- 限购、限贷等调控政策
- 经济发展和居民收入增长
