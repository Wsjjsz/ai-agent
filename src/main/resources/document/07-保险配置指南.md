# 保险配置指南

## 保险的基本功能
- **风险转移**：将个人可能面临的经济损失转移给保险公司
- **经济补偿**：发生保险事故后获得经济赔偿
- **储蓄功能**：部分保险产品兼具储蓄和投资功能
- **财富传承**：通过人寿保险实现指定传承

## 主要保险类型
### 人身保险
- **寿险**：以被保险人生存或死亡为给付条件
  - 定期寿险：保障特定期限，保费低、保障高
  - 终身寿险：保障终身，兼具储蓄功能
  - 两全保险：生存到期返还保费，死亡给付保额
- **健康保险**
  - 重大疾病险：确诊即赔付约定保额
  - 医疗保险：报销医疗费用
  - 长期护理险：因失能需护理时给付

### 财产保险
- 车险、家庭财产险、旅行险等

## 保险配置优先级
1. **意外险**：价格低、保障高，基础保障首选
2. **百万医疗险**：解决大病医疗费用
3. **重疾险**：弥补因病造成的收入损失
4. **定期寿险**：家庭经济支柱必备
5. **养老保险/年金险**：补充退休收入

## 保费预算建议
- 年保费支出建议控制在年收入的5%-15%
- 保障型保险优先于理财型保险
- 先保大人后保小孩，家庭支柱优先保障
