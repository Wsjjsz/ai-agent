# IPO与新股投资

## 什么是IPO
IPO（Initial Public Offering）即首次公开发行，是公司首次向公众出售股票并在证券交易所上市的过程。IPO标志着公司从私有公司转变为上市公司。

## IPO流程
1. **改制设立股份公司**：完成股份制改造
2. **上市辅导**：券商对公司进行规范运作辅导
3. **申报材料**：向交易所提交招股说明书等文件
4. **审核注册**：交易所审核、证监会注册
5. **路演询价**：向机构投资者推介并确定发行价
6. **发行上市**：公开发行并正式挂牌交易

## A股IPO制度
- **核准制→注册制**：科创板（2019）、创业板（2020）、主板（2023）全面推行注册制
- 注册制下以信息披露为核心，审核周期缩短
- 发行定价市场化，不再受23倍市盈率限制

## 新股申购（打新）
- **网上申购**：持有一定市值的股票即可参与
- **网下申购**：面向专业机构投资者
- 中签率通常很低（0.01%-0.1%），但上市首日上涨概率较大
- 注册制改革后破发风险增加，打新收益率下降

## IPO估值方法
- **可比公司法**：参考已上市同行业公司的估值水平
- **现金流折现法（DCF）**：对未来自由现金流折现求和
- **股息折现模型（DDM）**：对未来股息折现求和

## 新股投资注意事项
- 仔细阅读招股说明书，了解公司业务和风险
- 关注募集资金用途和投项目可行性
- 关注大股东持股比例和锁定期
- 确认保荐机构和中介机构的信誉
