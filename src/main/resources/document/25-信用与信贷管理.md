# 信用与信贷管理

## 个人信用体系
中国人民银行征信中心运营的个人信用信息基础数据库，记录个人的信贷信息，是金融机构审批贷款、信用卡的重要依据。

## 个人征信报告内容
- **个人基本信息**：身份信息、居住信息、职业信息
- **信贷记录**：贷款、信用卡的账户状态、还款记录
- **公共记录**：法院判决、欠税记录等
- **查询记录**：最近2年内的信用报告查询记录

## 影响信用评分的因素
- **还款历史**：是否按时还款（最重要因素）
- **债务水平**：总负债金额和负债率
- **信用历史长度**：信用账户的平均开户时间
- **新信用申请**：近期频繁申请贷款/信用卡会降低评分
- **信用类型多样性**：拥有不同类型的信贷产品

## 个人贷款产品
- **住房按揭贷款**：利率较低，期限最长30年
- **消费贷款**：用于个人消费，期限1-5年
- **经营贷款**：用于小微企业经营
- **助学贷款**：国家助学贷款，利率优惠

## 信用卡使用
- 享受免息期（通常20-56天），到期全额还款避免利息
- 最低还款额为应还款的10%，剩余部分按日计息
- 取现无免息期，从取现日当天开始计息
- 逾期会产生罚息和滞纳金，严重影响征信

## 债务管理建议
- 每月还款总额不超过月收入的50%
- 优先偿还高利率债务
- 建立应急基金，避免突发情况导致逾期
- 定期查询个人信用报告，发现问题及时处理
