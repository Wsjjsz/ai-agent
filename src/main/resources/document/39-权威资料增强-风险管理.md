# 权威资料增强：风险管理

资料性质：原创整理的 RAG 知识卡，不复制受版权保护书籍正文。适用于投资风险、组合回撤、VaR、压力测试、流动性风险、适当性和行为风险等问题召回。

## 风险的定义
投资风险不是单纯“价格下跌”，而是未来结果相对预期的不确定性，以及这种不确定性对财务目标造成损害的可能性。风险管理的目标不是消除风险，而是让承担的风险与目标和承受能力匹配。

收益和风险通常需要一起评估。承诺“高收益、低风险、保本”的非存款类投资，应高度警惕。

## 主要风险类型
- 市场风险：股价、利率、汇率、商品价格变化导致损失。
- 信用风险：债务人或交易对手违约。
- 流动性风险：无法及时以合理价格卖出资产。
- 通胀风险：购买力被物价上涨侵蚀。
- 利率风险：利率变化影响债券和估值。
- 汇率风险：外币资产折算回本币时波动。
- 集中度风险：过度集中于单一资产、行业、地区或策略。
- 操作风险：流程、系统、人为错误或欺诈导致损失。
- 行为风险：追涨杀跌、过度交易、锚定和损失厌恶。

## 风险指标
- 波动率：衡量收益波动程度，但不能完整描述极端损失。
- 最大回撤：衡量从高点到低点的最大跌幅。
- 夏普比率：衡量单位波动下的超额收益。
- Sortino 比率：更关注下行波动。
- VaR：在给定置信水平和期限下的潜在损失估计。
- 压力测试：假设极端情景下组合可能损失。
- 久期：债券组合对利率变化的敏感度。

## 风险管理方法
分散化可以降低非系统性风险，但不能消除系统性风险。资产配置、仓位控制、止损纪律、再平衡、流动性储备和保险保障都是风险管理工具。

风险预算是把组合总风险分配到不同资产或策略。风险平价关注不同资产对组合总风险的贡献，而不是只看资金比例。

## 投资者适当性
投资者适当性要求把合适的产品销售给合适的投资者。高波动、高杠杆、复杂结构、低流动性产品不适合所有人。

评估适当性要看年龄、收入、负债、投资经验、风险承受能力、投资目标、期限和流动性需求。

## 风险提示话术
当用户问“有没有稳赚”“能不能满仓”“能不能借钱投资”时，应提示不存在无风险高收益，避免杠杆和单一押注，并建议根据资金期限和风险承受能力分层配置。
