# 理财小白入门指南

## 1. 什么是理财？
理财是指通过合理的规划和投资，管理个人或家庭的财务状况，以实现财务目标和资产增值的过程。理财不仅包括如何赚钱，也包括如何省钱和管理钱。

## 2. 投资基本原则
- **分散投资**：不要把所有鸡蛋放在同一个篮子里，可以通过基金、股票、债券等不同资产类别降低风险。
- **长期投资**：复利是世界第八大奇迹，长期投资能更好地抵抗市场短期波动。
- **风险与收益**：高收益往往伴随着高风险。投资前必须评估自己的风险承受能力。

## 3. 看懂基本面指标
- **PE（市盈率）**：公司市值与净利润的比例，常用于估值。
- **PB（市净率）**：市值与净资产的比率。
- **ROE（净资产收益率）**：衡量企业运用股东资金的效率。

## 4. 常见误区
- 盲目跟风买股票，不看基本面。
- 借钱炒股（使用杠杆）。
- 频繁交易导致手续费侵蚀利润。
